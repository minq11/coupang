        오늘 주문 현황

        WING에 등록된 내 상품 목록

          쿠팡 WING Open API
          상태확인중…
          Vendor ID
          Access Key
          API 키 입력

          쿠팡 WING → 판매자지원 → Open API 관리에서 발급한 키를 입력하세요. 키는 이 브라우저에만 저장되며 쿠팡 API 서버 외에는 전송되지 않습니다.

          개발자라면 env.example.json을 env.json으로 복사해 써도 됩니다. env.json이 있으면 그 값이 우선합니다.

          데이터
          순위 기록-

          기록은 이 브라우저의 확장 저장소에만 보관됩니다. (키워드×상품당 최근 150회) 브라우저를 옮길 때는 백업 파일로 이전하세요.
