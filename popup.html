        오늘 주문 현황

        WING에 등록된 내 상품 목록

          쿠팡 WING Open API
          상태확인중…
          Vendor ID
          Access Key
          API 키 연결 방법
          1. 쿠팡 WING → 판매자지원 → Open API 관리에서 키 발급
          2. 확장 폴더의 env.example.json을 env.json으로 복사
          3. env.json에 Access Key · Secret Key · Vendor ID 입력
          4. chrome://extensions에서 확장 새로고침(↻)

          키는 내 PC의 env.json에만 저장되며 외부로 전송되지 않습니다.
