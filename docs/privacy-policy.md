# 개인정보처리방침 — 쿠팡 순위 파인더

최종 수정일: 2026-07-29

"쿠팡 순위 파인더" 크롬 확장 프로그램(이하 "본 확장")은 사용자의 개인정보를
소중히 여기며, 아래와 같이 처리 방침을 밝힙니다.

## 1. 수집하는 정보: 없음

본 확장은 **어떠한 개인정보도 개발자 또는 제3자의 서버로 수집·전송하지 않습니다.**

- 분석(analytics) 도구를 사용하지 않습니다.
- 사용 통계를 수집하지 않습니다.
- 광고를 표시하지 않습니다.
- 외부 스크립트를 로드하지 않습니다.

## 2. 브라우저에만 저장되는 데이터

아래 데이터는 기능 제공을 위해 **사용자의 브라우저 내부 저장소
(chrome.storage.local)에만** 저장되며, 외부로 전송되지 않습니다.

| 데이터 | 용도 | 저장 위치 |
|---|---|---|
| 순위 조회 기록 (키워드, 상품ID, 순위, 조회 시각) | 순위 변화 추적 기능 | 사용자 브라우저 |
| 입력한 상품ID, 조회 범위 설정 | 편의 기능 (재입력 방지) | 사용자 브라우저 |
| 쿠팡 WING Open API 키 (선택 입력 시) | 사용자 본인 계정의 상품/주문 조회 | 사용자 브라우저 |

사용자는 언제든지 확장 설정 탭 또는 확장 제거를 통해 위 데이터를 삭제할 수 있습니다.

## 3. 외부 통신

본 확장이 통신하는 서버는 다음이 전부입니다.

- **www.coupang.com** — 사용자가 열어둔 검색결과 페이지의 상품 목록을 읽기 위한
  통신으로, 사용자가 브라우저에서 쿠팡을 이용하는 것과 동일한 요청입니다.
- **api-gateway.coupang.com** — 사용자가 직접 발급·입력한 API 키로 본인 쿠팡
  계정의 상품/주문 정보를 조회하는 경우에만 호출됩니다. API 키를 입력하지
  않으면 이 통신은 발생하지 않습니다.

개발자가 운영하는 서버는 존재하지 않습니다.

## 4. 데이터 판매·공유

본 확장은 어떤 데이터도 판매하거나 제3자와 공유하지 않습니다.
수집하는 데이터 자체가 없습니다.

## 5. 아동의 개인정보

본 확장은 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

## 6. 방침 변경

방침이 변경되는 경우 본 문서와 웹스토어 설명에 반영합니다.
