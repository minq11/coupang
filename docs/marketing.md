# 마케팅 플랜 + 채널별 초안

부수입 프로젝트 규모(광고비 0원)에 맞춘 실행 문서입니다.
그대로 복붙해서 다듬어 쓸 수 있는 초안 포함.

---

## 1. 포지셔닝 한 줄

> **"내 상품 쿠팡 순위, 버튼 한 번에 10페이지까지 — 서버도, 월 구독료도 없이."**

경쟁 도구(아이템스카우트·헬프스토어·쿠파일럿 등)는 서버 크롤링 기반 월 구독형.
우리는 셀러 브라우저에서만 도는 로컬 도구라서 ① 저렴하고 ② 데이터가 내 것이고
③ 쿠팡이 서버 크롤러를 막아도 영향이 없다. 이 세 가지가 모든 메시지의 뼈대.

## 2. 타겟

| 우선순위 | 타겟 | 특징 | 메시지 포인트 |
|---|---|---|---|
| 1 | 1인 부업/초기 전업 셀러 | 상품 5~50개, 키워드 순위에 민감, 유료 SaaS 부담 | "무료로 시작, 월 구독료 없음" |
| 2 | 전업 소상공인 셀러 | 상품 50개+, 매일 순위 체크가 루틴 | "매일 하던 30분 작업이 30초" |
| 3 | 운영대행/컨설턴트 | 다계정, 보고서 필요 | "CSV로 고객 보고서까지" |

## 3. 채널 실행 순서 (돈 안 드는 순)

1. **크롬 웹스토어 검색 최적화** — 제목에 "쿠팡 순위" 포함(완료: 게시 자료 참조).
   스크린샷 품질이 설치 전환율의 대부분을 결정. GIF 데모 1개 필수.
2. **네이버 카페 정보성 글** — 셀러오션, 아프니까 사장이다 등.
   홍보 글이 아니라 "방법" 글에 도구를 자연스럽게 언급 (아래 초안).
3. **블로그 SEO 글 2~3개** — "쿠팡 순위 확인 방법" 등 검색 유입 키워드.
4. **유튜버 아웃리치** — 쿠팡 셀러 채널 5~10곳에 DM (아래 템플릿).
5. 유료 광고는 이 규모에서 비추천. 위 채널 반응 확인 후 판단.

## 4. 가격 (제안)

- **무료**: 순위 조회 무제한, 기록 3개 조합, 기록 보관 7일
- **프로 (평생 39,000원 또는 월 9,900원)**: 기록 무제한, CSV, 경쟁 분석, API 연동
- 평생 라이선스는 서버비가 없는 우리만 가능한 카드 — 경쟁 도구가 못 따라옴
- 순서: 완전 무료 베타(리뷰 확보) → 설치 500+ 후 유료 전환

## 5. 초안 모음

### 5-1. 네이버 카페용 정보성 글

제목: **쿠팡 내 상품 순위, 매일 확인하는 분들께 (수동으로 넘기지 마세요)**

```
쿠팡 하시는 분들 매일 아침 루틴이 비슷할 겁니다.
키워드 검색 → 1페이지 훑고 → 2페이지 → 3페이지... 내 상품 찾으면 엑셀에 기록.
상품 10개면 이것만 30분입니다.

몇 가지 방법을 정리하면:

1) 수동 확인 — 정확하지만 시간이 제일 아깝습니다.
2) 유료 순위추적 서비스 — 편하지만 월 3~9만원. 서버가 대신 크롤링하는
   방식이라 순위가 실제 노출과 다르게 잡히는 경우도 있습니다.
3) 크롬 확장으로 내 브라우저에서 확인 — 제가 요즘 쓰는 방식입니다.
   쿠팡에서 키워드 검색해두고 버튼 누르면 1~10페이지를 훑어서
   내 상품 순위를 찾아주고, 조회할 때마다 기록이 쌓여서
   어제 대비 몇 계단 올랐는지(▲▼)까지 보여줍니다.
   내 브라우저에서 도는 거라 실제 노출 순위 그대로고, 무료입니다.

(댓글로 물어보시면 쓰는 확장 알려드릴게요 — 규정상 본문 링크는 생략)
```

포인트: 본문에 링크를 넣지 않고 댓글 유도 → 광고 글 삭제 회피 + 댓글 상호작용.

### 5-2. 블로그 SEO 글 (검색 유입용)

타겟 검색어: `쿠팡 순위 확인`, `쿠팡 내 상품 순위`, `쿠팡 키워드 순위 조회`

제목: **쿠팡 상품 순위 확인하는 3가지 방법 (2026년 기준, 무료 포함)**

목차:
1. 쿠팡 순위가 중요한 이유 (노출 = 매출)
2. 방법 1 — 수동 확인: 정확하지만 느리다
3. 방법 2 — 유료 순위추적 SaaS: 장단점, 대표 서비스 비교표
4. 방법 3 — 크롬 확장 (무료): 설치 → 검색 → 버튼 한 번, 스크린샷 포함 사용기
5. 방법별 비교표 (시간/비용/정확도)
6. 결론: 상품 30개 이하면 3번으로 충분

본문 작성 팁: 3번 섹션에 실제 사용 GIF, 웹스토어 링크는 본문 1회 + 결론 1회만.

### 5-3. 유튜버 아웃리치 DM 템플릿

```
안녕하세요, ○○님 영상 잘 보고 있는 쿠팡 셀러 겸 개발자입니다.

셀러들이 매일 하는 순위 확인을 자동화하는 무료 크롬 확장을 만들었습니다.
- 검색결과 1~10페이지에서 내 상품 순위 자동 탐색
- 조회할 때마다 순위 변화(▲▼) 기록
- 서버 없이 브라우저에서만 동작 (계정 리스크 없음)

구독자분들께 유용할 것 같아 소개드립니다. 영상에서 다뤄주시면
시청자용 프로 버전 무료 코드를 제공해드리겠습니다.
부담 없이 한번 써보시고 판단해주세요: [웹스토어 링크]
```

### 5-4. 웹스토어 리뷰 요청 (확장 내 알림용 문구, 추후 구현 시)

```
쿠팡 순위 파인더가 도움이 되셨나요?
리뷰 한 줄이 다른 셀러분들께 큰 도움이 됩니다 🙏 [리뷰 남기기]
```

## 6. 출시 2주 실행 캘린더 (예시)

| 일차 | 할 일 |
|---|---|
| 1~2 | 지인 셀러 5~10명 베타 → 파싱 정확도 피드백 반영 |
| 3 | 스크린샷·GIF 촬영, 개인정보처리방침 URL 준비 |
| 4 | 웹스토어 제출 (심사 1~3일) |
| 5~7 | 블로그 글 2개 발행 |
| 8 | 카페 글 1개 (셀러오션) |
| 10 | 카페 글 1개 (아프니까 사장이다) |
| 12 | 유튜버 DM 5곳 발송 |
| 14 | 지표 점검: 설치 수, 리뷰, 유입 채널 → 다음 2주 계획 |

## 7. 성공 지표

- 4주차: 설치 100+, 리뷰 5개(4.5★+), 주간 활성 30%+
- 12주차: 설치 1,000+ → 이 시점에 유료 전환 결정
