# 크롬 웹스토어 게시 자료

웹스토어 등록 화면에 그대로 붙여넣을 수 있게 정리한 초안입니다.
게시 전에 실제 스크린샷 4~5장만 준비하면 됩니다.

---

## 기본 정보

| 항목 | 값 |
|---|---|
| 이름 | 쿠팡 순위 파인더 — 내 상품 순위 추적 |
| 카테고리 | 쇼핑 (또는 생산성 도구) |
| 언어 | 한국어 |

## 짧은 설명 (132자 이내)

> 쿠팡 검색결과에서 내 상품이 몇 위인지 버튼 한 번에 확인. 10페이지까지 자동 스캔, 순위 변화 기록, 광고/일반 구분, 경쟁 분석까지. 서버 없이 내 브라우저에서만 동작합니다.

## 자세한 설명

```
쿠팡 셀러라면 매일 확인하는 그 순위, 이제 버튼 한 번이면 됩니다.

■ 이런 분께 필요합니다
- 키워드 순위를 매일 수동으로 넘겨가며 확인하는 쿠팡 셀러
- 내 상품이 몇 페이지 몇 번째에 있는지 빠르게 알고 싶은 분
- 월 구독료 내는 분석 도구가 부담스러운 1인 셀러

■ 주요 기능
① 순위 조회 — 쿠팡에서 키워드 검색 후 버튼 한 번이면 1~10페이지를
   자동으로 훑어 내 상품의 순위를 찾아줍니다. 광고 순위와 일반(오가닉)
   순위를 구분하고, 검색결과 페이지 위에 내 상품을 하이라이트해줍니다.
② 순위 변화 추적 — 조회할 때마다 자동 기록. 직전 대비 상승/하락(▲▼),
   순위 변화 차트를 보여줍니다.
③ 경쟁 분석 — 해당 키워드 페이지의 평균가, 가격 분포, 광고 비중,
   내 상품의 가격/리뷰 위치를 요약해줍니다.
④ 엑셀(CSV) 내보내기 — 스캔 결과와 순위 기록을 파일로 저장.
⑤ 쿠팡 WING API 연동(선택) — 내 등록상품 불러오기, 키워드 제안,
   오늘 주문 현황 요약.

■ 다른 도구와 다른 점
- 서버가 없습니다. 모든 조회는 당신의 브라우저에서, 당신이 버튼을
  누른 순간에만 실행됩니다.
- 순위 기록과 API 키는 당신 PC에만 저장됩니다. 외부로 전송되는
  데이터가 없습니다.
- 백그라운드에서 몰래 도는 크롤링이 없어 계정에 부담을 주지 않습니다.

■ 사용법
1. 쿠팡(coupang.com)에서 키워드를 검색합니다.
2. 확장 아이콘을 누르고 내 상품 페이지 주소(URL)를 붙여넣습니다.
3. "순위 찾기"를 누르면 끝.
```

## 스크린샷 가이드 (1280×800, 4~5장)

1. **메인**: 검색결과 페이지 + 팝업에서 순위 카드가 보이는 장면 (▲2 델타 뱃지 포함)
2. **페이지 하이라이트**: 검색결과에서 내 상품에 주황 테두리 + "12위" 뱃지가 붙은 장면
3. **기록 탭**: 스파크라인 차트가 있는 순위 기록 목록
4. **경쟁 분석**: 가격 분포 히스토그램 + 인사이트 카드
5. **내 상품 탭**: 주문 현황 + 상품 목록 + 키워드 칩

## 심사 대응 — 권한 사유 (심사 문항에 그대로 사용)

| 권한 | 사유 |
|---|---|
| `activeTab` | 사용자가 팝업 버튼을 누른 순간, 현재 보고 있는 쿠팡 검색결과 탭에서 순위를 조회하기 위해 필요합니다. |
| `storage` | 순위 조회 기록과 사용자 설정(조회 범위, API 키)을 사용자 브라우저에 저장하기 위해 필요합니다. |
| `content_scripts` (coupang.com/np/search) | 사용자가 열어둔 쿠팡 검색결과 페이지의 상품 목록을 읽고, 내 상품을 하이라이트 표시하기 위해 필요합니다. 검색결과 페이지에서만 동작합니다. |
| `host_permissions` (api-gateway.coupang.com) | 사용자가 직접 발급·입력한 쿠팡 WING Open API 키로 본인 계정의 상품/주문 정보를 조회하기 위해 필요합니다. |

**원격 코드 없음**: 모든 코드는 패키지에 포함되어 있으며 외부 스크립트를 로드하지 않습니다.
**데이터 수집 없음**: 어떤 사용자 데이터도 개발자 서버로 전송하지 않습니다 (개인정보처리방침 참고).
